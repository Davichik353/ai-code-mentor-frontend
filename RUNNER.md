# Браузерный запуск

Запускать из корня frontend: `python -m http.server 8080`.
Открыть страницу в браузере, вставить код в основной редактор, выбрать язык запуска, при необходимости заполнить строки ввода и нажать «Запустить». Ctrl+Enter запускает выбранный язык. Выбор языка запуска независим от выбора языка AI-анализа.

Python: Pyodide 0.27.7 с cdn.jsdelivr.net, стандартная библиотека в пределах возможностей WebAssembly. При каждом запуске новый Worker/runtime; файлы и переменные предыдущего запуска не сохраняются. Нет серверной файловой системы, pip или доступа к SQLite backend. JavaScript: Worker, console и prompt; DOM недоступен. Вывод идёт через textContent.

Есть остановка, лимит 10 секунд после загрузки runtime, 60 секунд на загрузку, ограничение вывода 50 000 символов. Это не серверная IDE и не песочница для обработки чужих недоверенных программ: пользователь запускает код в своём браузере; Worker не изолирует сетевые ресурсы и память как отдельная виртуальная машина. Токены приложения Worker не получает. Не запускать незнакомый код.

Браузерная проверка: при наличии Playwright и Chromium выполнить `node tests/browser-runner.cjs` с работающим сервером на 8080. Скрипт проверяет ввод/вывод, ошибки, таймаут, остановку и текстовое отображение HTML; Python требует доступного CDN. Путь Chromium в скрипте — /usr/bin/chromium.
