# Учебный кабинет

Запустите backend на 8000 и статический frontend на 8080 с разрешённым FRONTEND_ORIGINS. Выберите русский или O‘zbekcha в верхней панели. Откройте «Учебный кабинет» / «O‘quv xonasi».

1. **Преподаватель:** создайте аккаунт, выберите режим преподавателя и сохраните. Создайте группу, передайте её код ученику и выдайте одно из шести упражнений (три темы × Python/JavaScript).
2. **Ученик:** в другом аккаунте вступите по коду. Откройте задание, введите решение и запустите тесты. Можно остановить выполнение. Изменение исходного кода делает прежний отчёт неактуальным: тесты нужно выполнить снова.
3. **Подсказки:** открываются по одной. Пример решения доступен после всех подсказок и описания своей попытки. Это учебные подсказки из библиотеки, не запрос к AI.
4. **Мини-защита:** объясните алгоритм и граничный случай, напишите изменённую версию по дополнительному условию, проверьте её на собственном вводе и объясните изменение. Отправьте работу преподавателю. Тесты можно отправить и с ошибками, чтобы получить помощь.
5. **Проверка:** преподаватель видит код, объяснения и отчёт тестов, принимает работу или возвращает на доработку с комментарием. Отчёты браузерные и не являются доверенной оценкой.
6. **Портфолио:** ученик видит принятые задания. Публикация имени, описания и названий работ включается отдельной настройкой, её можно отключить. Исходный код и ответы защиты не публикуются. Общая ссылка работает для других людей только при доступном размещении frontend/backend, а не на локальном компьютере.

При переключении языка поля текущего задания сохраняются в памяти страницы. Не перезагружайте страницу до отправки: несданный код и формы не сохраняются на сервере автоматически. Выполненные отправки и открытые подсказки сохраняются в SQLite. Словарь терминов доступен в кабинете. Основные кнопки редактора и регистрации переведены; некоторые старые второстепенные экраны остаются на английском.

## Проверки
При установленном Playwright/Chromium и запущенных локальных сервисах:

```bash
node tests/learning-flow.cjs
node tests/exercise-runtime.cjs
node tests/browser-runner.cjs
```

learning-flow проверяет двух пользователей, группу, задание, подсказки, тесты, изменение кода, защиту, приём, переключение языка, публикацию/отключение портфолио, отсутствие приватных данных и мобильную ширину. Использовать тестовую базу; аккаунты сценария удаляются после выполнения.

exercise-runtime проверяет решения всех шести упражнений в реальном браузере, ошибку, отмену и таймаут. Нужен соседний checkout backend; при другом расположении задать MENTOR_BACKEND. Python для чтения библиотеки: MENTOR_PYTHON (по умолчанию /workspace/.setup/venv/bin/python). Chromium: CHROMIUM_PATH (по умолчанию /usr/bin/chromium). Для Python необходим доступ к cdn.jsdelivr.net.

Результат тестов не проверяет педагогический эффект и не означает готовность к высоконагруженному публичному экзамену. Подробности серверного API и хранения — в backend/LEARNING.md.
