Как работает запуск
Код выполняется в вашем браузере. Python и JavaScript: без серверных файлов и установки пакетов. Для Python при каждом запуске загружается runtime с CDN; встроенная библиотека доступна частично. Лимит выполнения — 10 секунд.

AI Code Mentor

                
Помощник преподавателя для практики программирования в школах и учебных центрах: задания группам, подсказки ученикам и проверка отправленных работ.

            

            

                
Python и JavaScriptВыполнение кода в браузере

                
Группа и преподавательЗадание → решение → проверка

                
Русский и узбекскийИнтерфейс на двух языках

            

            

                

                    
Проблема

                    
    
                        
  • Ученики видят ошибку, но не всегда понимают её причину.
    • 
                        
  • Преподавателю нужно проверять решения всей группы.
    • 
                        
  • Готовый ответ сам по себе не подтверждает понимание ученика.
    • 
                    

                

                

                    
Решение

                    
    
                        
  • Преподаватель выдаёт задания своей группе.
    • 
                        
  • Ученик пишет код, запускает тесты и получает подсказки.
    • 
                        
  • Преподаватель видит отправленные работы и результаты тестов.
    • 
                    

                

                

                    
Бизнес-модель

                    
    
                        
  • Планируемая модель — подписка для школ и учебных центров.
    • 
                        
  • Стоимость зависит от числа учеников и лимита AI-анализов.
    • 
                        
  • Тариф и себестоимость предстоит проверить на пилоте.
    • 
                    

                

                

                    
Следующий этап

                    
    
                        
  • Провести пилот с преподавателем и учебной группой.
    • 
                        
  • Измерить время проверки, повторные попытки и затраты на AI.
    • 
                        
  • Результаты реального пилота пока не подтверждены.
    • 
                    

                

            

            
Тесты выполняются в браузере; преподаватель проверяет код и объяснение ученика. AI может ошибаться. Для Python нужен доступ к CDN; запуск ограничен 10 секундами. Доступность зависит от сети и сервера.
